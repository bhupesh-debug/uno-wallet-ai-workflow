# Notebooks

No notebooks are checked in. The demo is the pipeline itself — run it
with `python run_all.py` from the project root, then read
`reports/weekly_memo_example.md` (the latest week's memo, post review
gate) and `reports/metrics.json` (the evaluation). If a notebook walkthrough
is wanted later, it should call the same `src/` modules rather than
re-implementing them, so the notebook can never drift from the tested code.
