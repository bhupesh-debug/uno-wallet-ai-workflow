# AI Workflow That Makes Two People Do the Work of Ten

**For:** Uno Wallet — AI Business Analyst (YC P26, 2 founders)
**Author:** Bhupesh Chandra Dimri
**Stack:** Python 3, pandas, scikit-learn, matplotlib

## One-liner

A weekly performance-reporting workflow for a 2-person startup: raw numbers
in, a structured founder-grade memo out — with a human review gate that
re-derives every number from source data, and an evaluation harness that
scores the memo against hand-labelled synthetic ground truth.

## ⚠️ Read this first — what is real and what is not

- **All data is synthetic**, generated by `src/data_gen.py` (seeded, 8 weeks).
  Nothing here is real Uno Wallet data and no result is a claim about Uno.
- **The demo runs on a deterministic mock LLM adapter** (`MockLLMAdapter` in
  `src/llm_client.py`). It parses the prompt, computes deltas with plain
  arithmetic and assembles the memo from templates. It is NOT a language
  model. No real LLM was called, and **no API key exists for this build**.
- A `RealAPIAdapter` (OpenAI-compatible chat completions) is included for
  production use. Its key is read ONLY from the `UNO_LLM_API_KEY`
  environment variable at call time — never hardcoded, never in a file.
  Without it, the adapter raises a clear error and the demo is unaffected.
- **Field accuracy of 100% (168/168) measures the workflow plumbing** —
  the mock is deterministic arithmetic, so it should be exact. It does NOT
  prove a real LLM would be accurate. The evidence that matters for a real
  model is the review gate: in the seeded-error test it caught 3/3
  deliberately corrupted fields.
- **The manual time baseline (105 min/week) is an ESTIMATE** from a task
  breakdown, not a measured observation. Nobody timed a founder writing
  this memo by hand. Replace it with a real timing in week one of live use.
- **No manual error rate is claimed.** No human did these eight weeks by
  hand under observation, so there is nothing honest to compare against.
  The report gives the memo's measured field accuracy and the gate's
  seeded-error detection rate instead.
- **Adoption is unproven.** `reports/adoption_log.jsonl` records this demo
  run only. Real adoption needs four weeks of founders actually using it.

## The workflow

```
raw weekly rows ──▶ prompt (raw values only, no pre-computed deltas)
    ──▶ LLM client (mock by default) ──▶ memo + ##STRUCTURED## block
    ──▶ human review gate (re-derives every number from source data)
    ──▶ approve / needs_fix ──▶ audit log (JSONL)
```

The structured block is the contract: prose is for humans, the block is
what the gate and the evaluator check.

## How to run

```bash
python run_all.py            # data -> memos -> gate -> evaluation -> charts + reports/metrics.json
python -m tests.test_all     # test suite (prints a runtime "N passed" line)
```

To try the real adapter (your own key, your own account):

```bash
export UNO_LLM_API_KEY="..."        # never commit this; never paste it in chat
python -c "
from src.llm_client import RealAPIAdapter
from src.data_gen import generate
from src.workflow import run_workflow
m, f = generate()
print(RealAPIAdapter().generate(run_workflow('2026-W08', m, f, RealAPIAdapter())[1])[:800])
"
```

## Results (measured, mock adapter, 8 synthetic weeks)

| Measure | Result |
|---|---|
| Memo field accuracy vs ground truth | **100% (168/168 fields)** |
| Top-insight match | 8/8 weeks |
| Flag set correct | 8/8 weeks |
| Review-gate approvals | 8/8 weeks (0 issues on clean memos) |
| Seeded-error detection (gate) | **3/3 corrupted fields caught** |
| Pipeline runtime | ~0.01 s/week (measured) |
| Time saved | **95 min/week ≈ 82 h/year** (manual baseline is an estimate) |
| Error cases in the evaluation | 0 |

Edge cases the harness exercises: W03 rec_accuracy missing (memo says
"n/a", never invents); W05 signups/transactions near-tie for top mover
(either answer accepted); W06 negative transactions (flagged
DATA_QUALITY, excluded); W07 accuracy dip to 87% (RISK_ACCURACY_LOW
flag raised, investigation recommended); W01 no prior week (all changes
n/a).
